1) FIRST: validate feature parity

From the project root:

  python -m src.validation.feature_parity --sample-size 500

This builds artifacts/twitch/feature_store_36.joblib on first run, then compares
the new serving-time feature engine against Notebook 02.

2) THEN: run a local recommendation

  python -m src.inference.engine --user-id 30 --top-k 10

Flow:
  user_id
    -> Notebook-05 history + SVD + popularity retriever
    -> 200 candidates
    -> exact 36-feature engine
    -> HGB ranker
    -> Top 10

Do not add FastAPI/Redis/distributed replicas until feature parity passes.
